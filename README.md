
# C++ Fundamentals Practical

## Aim
To demonstrate basic C++ concepts including data types,
variables, constants, operators and input/output.

## Description
This program accepts student age and marks, calculates
percentage and checks passing status and eligibility.

## Concepts Used
- Data Types
- Variables and Constants
- Arithmetic Operators
- Relational Operators
- Logical Operators
- Conditional Operators
- cin and cout

## Compiler
G++ Compiler

## Compile
g++ main.cpp -o main

## Run
./main
