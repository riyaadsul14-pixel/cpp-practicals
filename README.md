# C++ Programming Practicals

## Introduction
This repository contains all 12 C++ programming practicals completed as part of the practical coursework. These programs demonstrate fundamental and advanced concepts of C++ programming, Object-Oriented Programming (OOP), STL, file handling, exception handling and design patterns.

## Objectives
- Understand basic C++ programming concepts.
- Implement Object-Oriented Programming principles.
- Understand inheritance and polymorphism.
- Practise function and operator overloading.
- Implement templates and exception handling.
- Perform file handling using C++ streams.
- Apply design patterns in real-world examples.

## How to Run the Programs
1. Open the required `.cpp` source file.
2. Copy the code into a C++ compiler such as OnlineGDB.
3. Select C++ as the programming language.
4. Click the Run button.
5. View the program output in the console.

## Repository Structure
Each practical is maintained in a separate C++ source file. The mini project contains its related source files and supporting documentation.

## Conclusion
This repository demonstrates the practical implementation of C++ programming concepts through different programs and a mini project. It helps develop programming skills, logical thinking and understanding of object-oriented software development.
